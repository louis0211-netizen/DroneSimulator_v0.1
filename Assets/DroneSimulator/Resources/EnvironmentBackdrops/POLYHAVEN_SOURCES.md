# Environment Backdrop Sources

These preview images and 1K EXR panoramas are used as lightweight iOS-compatible scene assets for the first MVP. Poly Haven assets are distributed under CC0.

- City: Wide Street 02, https://polyhaven.com/a/wide_street_02
- Forest: Hochsal Forest, https://polyhaven.com/a/hochsal_forest
- Mountain: Table Mountain 2, https://polyhaven.com/a/table_mountain_2
- Beach: Umhlanga Sunrise, https://polyhaven.com/a/umhlanga_sunrise
- License: https://polyhaven.com/license

Runtime panoramas are stored in `Assets/DroneSimulator/Resources/EnvironmentPanoramas/` and loaded by `TrainingGroundBuilder`.
