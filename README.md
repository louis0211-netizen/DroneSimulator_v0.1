# DroneSimulator_v0.1

Unity 6 / C# quadcopter flight simulator MVP for iOS iPhone landscape.

The first milestone focuses on physical flight behavior before expanding the game layer:

1. Flight Physics
2. Control Feel
3. iOS Input
4. HUD
5. Environment

## Target

- Unity 6.3 LTS `6000.3.23f1`
- C#
- Unity Physics / Rigidbody
- iOS Build Target
- Xcode install to iPhone
- Landscape orientation
- Mode 2 controls

## Current Scope

Implemented in this repository:

- Basic Unity project folders
- Modular flight physics core
- Quadcopter motor definitions
- Per-motor thrust and reaction torque
- Stabilized and Acro flight modes
- PID-based angle/rate control profile
- Stick dead zone, expo, and throttle curve
- Input state abstraction
- iPhone landscape dual virtual joystick scripts
- Unity Editor scene builder
- Minimal camera, HUD, and training ground hooks

## Quick Start in Unity

1. Open this folder with Unity 6.3 LTS:
   `C:\Users\HP\Documents\Codex\2026-09-04\dronesimulator-v0-1-ios-iphone-landscape`
2. Wait for Unity to import scripts.
3. Run `Drone Simulator > Create MVP Training Scene`.
4. Run `Drone Simulator > Configure iOS Landscape Build`.
5. Optional: run `Drone Simulator > Build iOS Xcode Project`.
6. Open `Assets/DroneSimulator/Scenes/MVP_TrainingGround.unity` if it is not already active.
7. Press Play.

The generated scene includes:

- Quadcopter Rigidbody
- Default drone preset asset
- Training ground
- FPV and chase cameras
- Landscape touch HUD
- Left and right virtual joysticks
- ARM, RESET, CAMERA, and MODE buttons

## Controls

Mode 2:

- Left joystick Y: Throttle
- Left joystick X: Yaw
- Right joystick Y: Pitch
- Right joystick X: Roll

Buttons:

- ARM / DISARM
- RESET
- CAMERA
- FLIGHT MODE

## Suggested Unity Setup

1. Set Build Target to iOS.
2. Set orientation to Landscape Left or Landscape Right.
3. Use the scene builder menu above, or manually add:
   - `Rigidbody`
   - `DronePhysics`
   - `FlightController`
   - `DroneInputManager`
4. Add four motor child transforms or use the default motor layout generated by `DronePhysics`.
5. Add HUD and virtual joystick UI later in the scene.

## GitHub CI

GitHub Actions workflows are included under `.github/workflows`:

- `fallback-csharp-checks.yml`: Windows runner, no Unity license required, uses local stubs.
- `unity-compile.yml`: runs local stub compile checks and, when `UNITY_LICENSE` is configured, runs a GameCI Unity import/build check.
- `ios-xcode-export.yml`: manual macOS iOS Xcode export, requires Unity secrets.

See `GITHUB_SETUP.md` for repository setup and required secrets.

After Unity is installed and Unity Hub is signed in, run:

```powershell
powershell -ExecutionPolicy Bypass -File "Tools\Run-UnityBatchCompile.ps1"
```

You can also double-click or run:

```powershell
Tools\Run-UnityBatchCompile.cmd
```

To generate the MVP scene and configure iOS from Unity batchmode:

```powershell
Unity.exe -batchmode -quit -projectPath "." -executeMethod DroneSimulator.Editor.DroneSimulatorBuildPipeline.CreateSceneAndConfigureIos -logFile "work\unity-create-scene.log"
```

To install the selected Unity Editor with iOS module through Unity CLI:

```powershell
powershell -ExecutionPolicy Bypass -File "Tools\Install-UnityEditor.ps1"
```
